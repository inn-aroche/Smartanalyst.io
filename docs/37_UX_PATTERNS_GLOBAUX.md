# UX: Global Patterns

## Components
- Forms (validation, errors)
- Loading states (skeleton, progress)
- Modals (close on Escape)
- Data tables (sortable, filterable)
- Charts (responsive, legend)
- Buttons (primary, secondary, danger)
- Color palette (Indigo primary, Emerald success, Amber warning, Red error)
- Typography (Inter, 1.125 scale)
